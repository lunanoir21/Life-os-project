Merak edilenler

Life OS hakkında en çok sorulan sorular ve cevapları.

Life OS tam olarak nedir?
+
Life OS; görevler, alışkanlıklar, finans, hedefler ve daha fazlasını tek bir çatı altında birleştiren, yerel öncelikli ve açık kaynaklı bir kişisel hayat yönetim sistemidir. Verileriniz cihazınızda kalır, bulut bağımlılığı yoktur.
Verilerim güvende mi?
+
Kesinlikle. Life OS "Local-first" (Yerel Öncelikli) bir felsefeyle tasarlanmıştır. Tüm verileriniz cihazınızdaki yerel bir SQLite veritabanında saklanır. İnternet bağlantısı gerekmez ve sunuculara veri gönderilmez.
Kurulumu zor mu?
+
Hayır! Sadece 3 komutla başlayabilirsiniz: clone, install ve run. Docker tercih ediyorsanız, tek bir komutla container ayağa kaldırabilirsiniz. Hiçbir yapılandırma dosyası düzenlemenize gerek yoktur.
Neden Rust kullanıldı?
+
Rust, bellek güvenliği ve olağanüstü performans sunar. Life OS'un arkayüzü (backend) Rust ile yazılmıştır, bu da yerel veritabanı işlemlerinin anlık ve sorunsuz gerçekleşmesini sağlar. Cihazınızın kaynaklarını minimum düzeyde tüketir.
Ücretsiz mi?
+
Evet, tamamen! Life OS MIT lisansı altında açık kaynaklıdır. Abonelik, gizli ücret veya premium kilidi yoktur. İstediğiniz gibi kullanabilir, değiştirebilir ve katkıda bulunabilirsiniz.

Başlarken

Sıfır yapılandırma. Tek komut.

Hesap yok, bulut yok, izleme yok. Sadece klonlayın, çalıştırın ve verilerinizin sahibi olun.

1
Depoyu klonlayın
# Klonla ve gir git clone https://github.com/lunanoir21/Life-os-project.git cd Life-os-project
2
Veritabanını kurun
bun install bun run db:push bun run db:seed # isteğe bağlı demo verisi
3
Geliştirme sunucusunu başlatın
bun run dev # → http://localhost:3000

🐳 Docker mı tercih ediyorsunuz?

SQLite'ın adlandırılmış bir birime kalıcı olarak kaydedildiği çok aşamalı yapı. Şema ilk başlatmada otomatik olarak uygulanır.

bun run docker:up # arka planda oluştur ve başlat
