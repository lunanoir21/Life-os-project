# 🌍 Internationalization (i18n) Guide

Life OS supports multiple languages through a comprehensive i18n system.

## Supported Languages

Currently, Life OS supports the following languages:

- 🇬🇧 **English** (`en`) - Default
- 🇹🇷 **Turkish** (`tr`) - Türkçe
- 🇪🇸 **Spanish** (`es`) - Español
- 🇩🇪 **German** (`de`) - Deutsch
- 🇫🇷 **French** (`fr`) - Français

## Architecture

### Directory Structure

```
src/lib/i18n/
├── index.ts              # Main i18n configuration and hooks
└── translations/
    ├── en.ts            # English (base language)
    ├── tr.ts            # Turkish
    ├── es.ts            # Spanish
    ├── de.ts            # German
    └── fr.ts            # French
```

### How It Works

1. **Translation Files**: Each language has its own TypeScript file that exports a translation object
2. **Type Safety**: All translations are strictly typed based on the English translation keys
3. **Nested Keys**: Supports dot notation for nested translation keys (e.g., `nav.dashboard`)
4. **Dynamic Values**: Supports parameter interpolation (e.g., `{count}`)
5. **Arrays**: Supports array values for things like motivational subtitles

## Usage

### Basic Translation

```tsx
import { useTranslation } from '@/lib/i18n'

function MyComponent() {
  const { t } = useTranslation()
  
  return <h1>{t('dashboard.goodMorning')}</h1>
}
```

### Translation with Parameters

```tsx
const { t } = useTranslation()

// Will replace {count} with the actual value
const message = t('habits.streakOnFire', { count: 5 })
// Result: "You're on a 5-day streak! Keep it going!"
```

### Array Translations

```tsx
const { tArray } = useTranslation()

// Get an array of values
const subtitles = tArray('dashboard.morningSubtitles')
// Result: ['Start your day with intention', 'A fresh start awaits', ...]
```

### Get Current Language

```tsx
const { language } = useTranslation()

// Returns the current language code (e.g., 'en', 'tr', 'es')
console.log(language)
```

## Adding a New Language

### Step 1: Create Translation File

Create a new file in `src/lib/i18n/translations/`:

```typescript
// src/lib/i18n/translations/it.ts
import type { TranslationKeys } from './en'

const it: TranslationKeys = {
  appName: 'Life OS',
  save: 'Salva',
  cancel: 'Annulla',
  // ... translate all keys from en.ts
}

export default it
```

### Step 2: Register the Language

Update `src/lib/i18n/index.ts`:

```typescript
import it from './translations/it'

const translations: Record<string, TranslationKeys> = {
  en,
  tr,
  es,
  de,
  fr,
  it, // Add new language
}

export const availableLanguages = [
  { code: 'en', label: 'English', nativeLabel: 'English', flag: '🇬🇧' },
  { code: 'tr', label: 'Turkish', nativeLabel: 'Türkçe', flag: '🇹🇷' },
  { code: 'es', label: 'Spanish', nativeLabel: 'Español', flag: '🇪🇸' },
  { code: 'de', label: 'German', nativeLabel: 'Deutsch', flag: '🇩🇪' },
  { code: 'fr', label: 'French', nativeLabel: 'Français', flag: '🇫🇷' },
  { code: 'it', label: 'Italian', nativeLabel: 'Italiano', flag: '🇮🇹' }, // Add new language
] as const

export type LanguageCode = 'en' | 'tr' | 'es' | 'de' | 'fr' | 'it' // Add to type
```

### Step 3: Update Setup Wizard (Optional)

Update the languages array in `src/components/lifeos/setup/setup-wizard.tsx`:

```typescript
const languages = [
  { code: 'en', label: 'English', flag: '🇬🇧' },
  { code: 'tr', label: 'Turkish', flag: '🇹🇷' },
  { code: 'es', label: 'Spanish', flag: '🇪🇸' },
  { code: 'de', label: 'German', flag: '🇩🇪' },
  { code: 'fr', label: 'French', flag: '🇫🇷' },
  { code: 'it', label: 'Italian', flag: '🇮🇹' }, // Add new language
]
```

### Step 4: Export the Translation

Add the export to `src/lib/i18n/index.ts`:

```typescript
export { en, tr, es, de, fr, it }
```

## Translation Keys Structure

The translation keys are organized by feature area:

```typescript
{
  // Common words
  save: 'Save',
  cancel: 'Cancel',
  delete: 'Delete',
  
  // Navigation
  nav: {
    dashboard: 'Dashboard',
    tasks: 'Tasks',
    notes: 'Notes',
    // ...
  },
  
  // Feature-specific
  tasks: {
    title: 'Tasks',
    newTask: 'New Task',
    // ...
  },
  
  // Settings
  settings: {
    title: 'Settings',
    language: 'Language',
    // ...
  },
  
  // Toast messages
  toast: {
    saved: 'Saved',
    saveFailed: 'Save failed',
    // ...
  }
}
```

## Best Practices

### 1. Always Use Translation Keys

❌ **Bad:**
```tsx
<button>Save</button>
```

✅ **Good:**
```tsx
<button>{t('save')}</button>
```

### 2. Use Consistent Key Naming

- Use camelCase for keys
- Group related translations
- Use descriptive names

### 3. Maintain Type Safety

Always ensure new translations match the `TranslationKeys` type from `en.ts`:

```typescript
const tr: TranslationKeys = {
  // TypeScript will error if keys don't match English
}
```

### 4. Parameter Naming

Use clear parameter names in braces:

```typescript
// Good parameter names
streakOnFire: "You're on a {count}-day streak!",
greeting: "Hello, {name}!",
```

### 5. Handle Pluralization

For languages with complex plural rules, provide separate keys:

```typescript
habitCount: 'habit',
habitCountPlural: 'habits',
```

## Changing Language

### From Settings

Users can change their language preference in Settings → Appearance → Language.

### From Setup Wizard

During initial setup, users can select their preferred language.

### Programmatically

```typescript
import { useAppStore } from '@/stores/app-store'

const { setLanguage } = useAppStore()
setLanguage('es') // Change to Spanish
```

## Persistence

The selected language is persisted in:
- **Zustand Store**: `useAppStore` with `persist` middleware
- **Local Storage**: Under key `lifeos-app-store`

## Troubleshooting

### Missing Translation

If a key is not found, the system falls back to:
1. The key itself (e.g., `nav.dashboard` → "nav.dashboard")
2. English translation (if available)

### Type Errors

If you get TypeScript errors when adding translations:
1. Ensure your translation object matches `TranslationKeys`
2. Check for typos in key names
3. Verify nested structure matches English version

### Language Not Showing

If a new language doesn't appear:
1. Check it's added to `availableLanguages` array
2. Verify it's in the `LanguageCode` type
3. Ensure translation file is imported
4. Clear browser cache/local storage
